# Fakta 1.1 — Akar `Cargo.toml`

**Sumber primer:** `Cargo.toml` (akar workspace)
**Tugas:** 1.1 Ekstraksi fakta `Cargo.toml`
**Requirements yang divalidasi:** 4.1, 4.2, 4.3, 4.4, 4.5, 7.6, 8.6, 13.10, 15.3, 15.4
**Catatan metode:** seluruh kutipan diambil verbatim dari `Cargo.toml` pada commit kerja saat ekstraksi; nomor baris merujuk pada berkas saat ini. Ejaan kebab/underscore dipertahankan persis seperti tertulis upstream.

## 2. Workspace dan target dokumentasi

### 2.1 Blok `[workspace]` verbatim (baris 16–21)

```toml
[workspace]
members = [
    ".",
    "examples/run_wasm",
    "examples/native_webgl",
]
```

### 2.2 Blok `[package.metadata.docs.rs]` verbatim (baris 23–26)

```toml
[package.metadata.docs.rs]
all-features = true
default-target = "x86_64-unknown-linux-gnu"
targets = ["wasm32-unknown-unknown"]
```

### 2.3 Fakta turunan

- Crate `arabella` diuji terhadap dua target dokumentasi: host `x86_64-unknown-linux-gnu` (default) dan `wasm32-unknown-unknown` (eksplisit). Hal ini menyokong klaim Bab 3 bahwa target browser adalah `wasm32-unknown-unknown`.
- Anggota workspace mencakup akar (`.`) plus dua contoh: `examples/run_wasm` dan `examples/native_webgl`. Demo interaktif Bab 3.6 dijalankan dari `examples/native_webgl` via `cargo run_wasm -p native_webgl --release`.

## 4. Dependensi target-spesifik non-WASM (`[target.'cfg(not(target_arch = "wasm32"))'.dependencies]`)

### 4.1 Blok verbatim (baris 48–50)

```toml
[target.'cfg(not(target_arch = "wasm32"))'.dependencies]
rayon = { version = "1.11.0", optional = true }
thread_local = { version = "1.1.9", optional = true }
```

### 4.2 Fakta turunan

- `rayon` versi `1.11.0` adalah dependensi **opsional** dan **hanya tersedia pada target non-wasm**. Klaim Bab 3 bahwa "Rayon adalah dependensi opsional yang belum dipanggil pada hot path" konsisten dengan `optional = true` di sini.
- `thread_local` versi `1.1.9` juga opsional dan non-wasm; kedua crate ini ditarik bersama via feature `multithreading` (lihat §6).

### 5.2 Fakta turunan

| Klaim Bab 3 | Bukti verbatim | Lokasi |
|---|---|---|
| Target WASM eksplisit pada `wasm32-unknown-unknown` | `[target.'cfg(target_arch = "wasm32")'.dependencies]` + `targets = ["wasm32-unknown-unknown"]` | `Cargo.toml:57` & `Cargo.toml:26` |
| Akses ke konteks WebGL 2.0 | feature `web-sys` `"WebGl2RenderingContext"` | `Cargo.toml:70` & duplikat `Cargo.toml:74` |
| Tidak ada API WebGL 1.0 maupun WebGPU | tidak terdapat string `WebGlRenderingContext` (tanpa `2`) maupun `WebGpu*` di blok ini | `Cargo.toml:57-87` |

> Dua kemunculan `"WebGl2RenderingContext"` (baris 70 dan 74) merupakan duplikat redundan di sumber; kedua-duanya memilih API yang sama (WebGL 2.0). Tidak ada implikasi runtime, tetapi dicatat di sini agar narasi Bab 3 tetap akurat.

> Seluruh dependensi WASM di blok ini ditandai `optional = true` dan ditarik via feature `webgl = ["dep:js-sys", "dep:web-sys", "dep:wasm-bindgen"]` (lihat §6).

### 5.3 Daftar fitur `web-sys` yang relevan untuk klaim Bab 3

- Konteks WebGL 2.0: `WebGl2RenderingContext`, `WebGlContextAttributes`, `WebGlProgram`, `WebGlUniformLocation`, `WebGlBuffer`, `WebGlShader`, `WebGlTexture`, `WebGlFramebuffer`, `WebGlRenderbuffer`, `WebGlVertexArrayObject`.
- Integrasi DOM/canvas: `HtmlCanvasElement`, `Window`, `Document`, `Element`, `HtmlElement`, `CssStyleDeclaration`, `DomRect`, `DomRectReadOnly`.
- Event input untuk demo interaktif (Bab 3.6): `MouseEvent`, `WheelEvent`, `KeyboardEvent`.
- Telemetri overlay FPS (Bab 3.6): `Performance`, `console`.

## 6. Blok `[features]`

### 6.1 Blok verbatim (baris 89–94)

```toml
[features]
default = ["std", "png"]
std = ["fearless_simd/std"]
webgl = ["dep:js-sys", "dep:web-sys", "dep:wasm-bindgen"]
png = ["std", "dep:png"]
multithreading = ["std", "dep:rayon", "dep:thread_local"]
```

### 6.2 Tabel feature flag untuk narasi Bab 3

| Feature | Definisi verbatim | Implikasi Bab 3 |
|---|---|---|
| `default` | `["std", "png"]` | Build default mengaktifkan `std` dan `png`; `multithreading` **tidak** termasuk default. |
| `std` | `["fearless_simd/std"]` | Mengaktifkan jalur `std` di crate `fearless_simd`. |
| `webgl` | `["dep:js-sys", "dep:web-sys", "dep:wasm-bindgen"]` | Membuka jembatan WebGL 2.0 ke browser; hanya berarti pada target `wasm32`. |
| `png` | `["std", "dep:png"]` | Dukungan dekode/enkode PNG via crate `png` opsional. |
| `multithreading` | `["std", "dep:rayon", "dep:thread_local"]` | **Opt-in eksplisit**: menarik `rayon = "1.11.0"` dan `thread_local = "1.1.9"` (keduanya `optional = true` pada blok target non-wasm di §4). Mendukung klaim Bab 3 bahwa Rayon adalah dependensi opsional yang belum dipanggil pada hot path. |

### 6.3 Catatan pada AC 4.5 dan AC 8.6

- `multithreading = ["std", "dep:rayon", "dep:thread_local"]` adalah satu-satunya feature yang menarik `rayon`. Karena tidak termasuk `default`, build standar (`cargo build`) tidak menyertakan Rayon.
- Pasangan `dep:rayon` + `dep:thread_local` selalu hadir bersama via feature ini, sesuai konvensi yang dipakai di Vello-style hybrid renderer.
- Klaim "paralelisme CPU bersifat potensial" pada Bab 3.5 (task 2.8) didukung oleh: (a) dependensi opsional `rayon`, (b) feature non-default, (c) tidak ada penarikan otomatis pada build default.

## 7. Profil rilis (`[profile.release]`)

### 7.1 Blok verbatim (baris 107–114)

```toml
[profile.release]
opt-level = 3
lto = "fat"
codegen-units = 1
panic = "abort"
overflow-checks = false
debug = false
strip = true
```

### 7.2 Fakta turunan (informatif untuk Bab 3.6 dan Bab 4)

- `lto = "fat"` + `codegen-units = 1` memungkinkan inlining lintas crate (kurbo, lyon, fearless_simd) yang relevan untuk klaim performa pra-pemrosesan CPU.
- `panic = "abort"` mengurangi ukuran binari WASM dengan menghapus tabel unwinding.
