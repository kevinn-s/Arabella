### 2.5 `record_per_scanline_crossings` — akumulator signed-area per scanline

- Lokasi: `src/blocks.rs:710-757`
- Anotasi: `#[inline(always)]` (`src/blocks.rs:709`).
- Signature:

```rust
fn record_per_scanline_crossings(crossings: &mut [i16; TILE_H], y0: i32, y1: i32)
```

- Deskripsi: untuk satu segmen garis vertikal (atau bagiannya) dalam satu ubin, fungsi ini mengakumulasi *signed y-overlap* terhadap delapan strip scanline `[r*256, (r+1)*256)` ke array `crossings: &mut [i16; TILE_H]` (delapan akumulator i16, satu per scanline). Tanda: garis turun (`y0 < y1`) → −1 winding (`-256`), garis naik (`y0 > y1`) → +1 winding (`+256`). Akumulasi memakai `saturating_add` untuk i16.
- Catatan komentar dokumentasi (`src/blocks.rs:691-708`): ini adalah akumulator *signed area* kanonik gaya Blaze / FreeType / Skia. Alasan signed-area (bukan crossings tunggal): MSAA pada GPU melakukan multisampling sub-piksel, sehingga backdrop per-scanline harus melacak akumulasi winding pada posisi sub-piksel untuk menghindari residu winding yang menggariskan seam.

Setiap varian: menghitung delta `dx`, `dy` (selalu positif setelah pembalikan tanda), origin baris ubin pada F24Dot8 via `(row << (8 + TILE_H_LOG2))`, lalu menjalankan loop DDA Bresenham-like dengan akumulator `mod_` (`pp % dy`) dan `lift = p / dy`, `rem = p % dy` untuk membagi segmen ke `bin_line_in_row` per baris ubin.

### 3.2 Tiga kasus khusus (cabang kode terpisah di `bin_line`)

| Kasus khusus | Kondisi | Penanganan | Lokasi |
|---|---|---|---|
| **Horizontal-degenerate** | `p0y == p1y` (segmen horizontal murni) | early-return; tidak diemit (tidak menyumbang winding) | `src/blocks.rs:115-117` |
| **Single-row** (segmen muat di satu baris ubin) | `row0 == row1` setelah konversi y → tile-row | langsung memanggil `bin_line_in_row` dengan `local_y` relatif ke origin baris ubin; tidak menjalankan loop DDA | `src/blocks.rs:134-138` (DOWN), `src/blocks.rs:149-153` (UP) |
| **Vertical-degenerate** | `p0x == p1x` (segmen vertikal murni) di dalam `bin_line_in_row` | mendeteksi kolom ubin tunggal via `f24dot8_to_tile_col(p0x) - bounds.min_col`, lalu langsung `push_to_tile` tanpa loop DDA | `src/blocks.rs:366-374` |

Kasus tambahan (recursive subdivision, bukan bagian dari "tiga kasus khusus" namun dicatat untuk kelengkapan): jika `dx > MAXIMUM_DELTA || dy > MAXIMUM_DELTA`, segmen dipecah dua secara rekursif via midpoint sebelum DDA dijalankan (`src/blocks.rs:119-126`).

## 5. Format fixed-point

### 5.1 `F24Dot8` — koordinat segmen (24.8 fixed-point, i32)

- Tipe storage: `i32` (32 bit total: 24 bit integer + 8 bit fraksional).
- Skala: 1 piksel = `256` unit F24Dot8 (geser 8 bit). Konstanta `TILE_W_F24DOT8 = 16 << 8 = 4096` dan `TILE_H_F24DOT8 = 8 << 8 = 2048` (`src/blocks.rs:10-11`).
- Pemakaian: seluruh argumen `p0x, p0y, p1x, p1y` pada `bin_line`, `build_block`, `bin_line_in_row`, dan empat varian outer/inner DDA; juga endpoint yang disimpan di `Block` (`src/blocks.rs:23-39`, dengan komentar `Range: x ∈ [0, TILE_W * 256], y ∈ [0, TILE_H * 256]` di `src/blocks.rs:24-25`).
- Helper konversi:
  - `fn f24dot8_to_tile_col(x: i32) -> i32 { x >> (8 + TILE_W_LOG2) }` (`src/blocks.rs:761-764`)
  - `fn tile_col_to_f24dot8(col: i32) -> i32 { col << (8 + TILE_W_LOG2) }` (`src/blocks.rs:766-768`)
  - Pergeseran `8 + TILE_*_LOG2` menjabarkan 8 bit fraksional + log2(ukuran ubin pada sumbu yang bersangkutan).
- Konstanta batas amplifikasi delta: `MAXIMUM_DELTA: i32 = 2048 << 8` (= `524288` F24Dot8 unit, ekuivalen 2048 piksel) di `src/blocks.rs:15`.

### 5.2 `8.8 fixed-point` — akumulator winding per scanline (i16)

- Tipe storage: `i16` per scanline; per ubin disimpan dalam array `[i16; TILE_H]` (delapan akumulator, satu per scanline) yang diisi oleh `record_per_scanline_crossings` (`src/blocks.rs:710`).
- Skala: 1 winding penuh = `256` unit (8 bit fraksional). Konvensi tanda eksplisit (`src/blocks.rs:702-704`):
  - garis turun (DOWN, `y0 < y1`) → −1 winding (= `-256` di 8.8)
  - garis naik (UP, `y0 > y1`) → +1 winding (= `+256` di 8.8)
- Penambahan: `saturating_add` agar tidak overflow i16 untuk segmen yang ekstrem (`src/blocks.rs:735, 740, 745, 749`).
- Sumber konvensi: komentar dokumentasi `src/blocks.rs:691-708` menyebut "*This is the canonical Blaze / FreeType / Skia signed-area accumulator.*"
- Output array dipakai oleh tahap emisi tile (lihat `src/builder.rs` dan `src/tile.rs`) sebagai field `backdrop: [i16; 8]` per `Tile` untuk propagasi backdrop kiri-ke-kanan dan untuk fragment shader GPU.
