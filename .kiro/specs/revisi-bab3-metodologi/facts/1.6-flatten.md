# Fakta 1.6 — Flattening Pipeline (`src/path.rs` & `src/flatten.rs`)

Read-only fact extraction untuk Task 1.6. Sumber: pembacaan langsung
`src/path.rs` dan `src/flatten.rs` pada repositori Arabella. Seluruh nomor baris
mengacu pada berkas terkait pada saat ekstraksi.

Cakupan:
- Signature dan dokumentasi singkat `convert_cubics_to_quadratic_curves` dan
  `estimate_number_of_quadratic_curves` (Subbab target Bab 3: 3.5 Perancangan
  Algoritma).
- Alur De Casteljau midpoint subdivision pada `flatten_quadratic` /
  `flatten_recursive` yang mengubah kuadratik menjadi segmen garis pada format
  `F24Dot8`.

Format tetap (relevan di seluruh dokumen ini):
- `F24Dot8` = 24.8 fixed-point yang disimpan sebagai `i32`, dengan skala
  `256 = 1 piksel`. Konversi `f32 → F24Dot8` dilakukan oleh
  `f32_to_f24dot8` (`src/path.rs:333`) dengan pembulatan simetris ke nilai
  bulat terdekat (`scaled + 0.5` untuk non-negatif, `scaled - 0.5` untuk
  negatif).

## 1. Konstanta dan invarian numerik di `src/path.rs`

Verbatim header konstanta dengan nomor baris (`src/path.rs:7-11`):

```rust
const MAX_QUADS: usize = 16;
const TO_QUAD_TOL: f32 = 0.5;
const EPSILON: f32 = 1e-6;
pub(crate) const SQRT_TOL: f32 = 0.5;
pub(crate) const TOL: f32 = SQRT_TOL * SQRT_TOL;
```

Tafsir:
- `MAX_QUADS = 16` membatasi jumlah maksimum sub-kuadratik per kubik tunggal,
  juga menentukan panjang look-up table `LUT` di `estimate` (`src/path.rs:377-390`)
  dan ukuran buffer keluaran `[f32; 96]` di `convert_cubics_to_quadratic_curves`
  (panjang 96 = 2 + 4 × `MAX_QUADS`; lihat layout di §2).
- `TO_QUAD_TOL = 0.5` adalah faktor toleransi tahap kubik→kuadratik;
  `accuracy * TO_QUAD_TOL` dipakai untuk menghitung
  `max_hypot2 = 432.0 * q_accuracy * q_accuracy` di
  `estimate_number_of_quadratic_curves` (`src/path.rs:352-375`).
- `TOL = SQRT_TOL * SQRT_TOL = 0.25` adalah toleransi `accuracy` yang dilewatkan
  ke `estimate_number_of_quadratic_curves` saat `fill_impl` memproses
  `PathEvent::Cubic` (`src/path.rs:228`).

## 2. `convert_cubics_to_quadratic_curves` (`src/path.rs:391-475`)

### 2.1 Signature

```rust
fn convert_cubics_to_quadratic_curves<S: Simd>(
    simd: S,
    p0: &Point<f32>,
    p1: &Point<f32>,
    p2: &Point<f32>,
    p3: &Point<f32>,
    n: usize,
) -> [f32; 96]
```

(`src/path.rs:391-398`).

### 2.2 Peran dan dokumentasi singkat

Tidak ada doc-comment di atas fungsi; dokumentasi diambil dari komentar inline
dan struktur kode:

- Mengonversi satu kurva Bézier kubik `p0, p1, p2, p3` ke barisan `n`
  sub-kurva Bézier kuadratik. `n` dihitung sebelumnya oleh
  `estimate_number_of_quadratic_curves` (lihat §3) dan diklem oleh
  `MAX_QUADS = 16`.
- Strategi: sampling kubik pada interval seragam `dt = 0.5 / n` di domain `t`,
  lalu rekonstruksi titik kontrol kuadratik dari pasangan titik on-curve
  ganjil/genap. Implementasi memakai jalur SIMD `f32x8` dari crate
  `fearless_simd` untuk mengevaluasi empat nilai `t` sekaligus per iterasi.
- Polinomial kubik dievaluasi melalui koefisien Horner `coeff_a, coeff_b,
  coeff_c, coeff_d` (`src/path.rs:412-415`):
  - `coeff_a = (p1 - p2) * 3 + (p3 - p0)`
  - `coeff_b = (p0 - 2*p1 + p2) * 3`
  - `coeff_c = (p1 - p0) * 3`
  - `coeff_d = p0`
  Evaluasi: `((coeff_a * t + coeff_b) * t + coeff_c) * t + coeff_d`
  (`src/path.rs:425-427`, memakai pola `mul_add` SIMD).
- Titik on-curve genap dan ganjil dipisah ke dua array sementara `even_pts`
  dan `odd_pts`, lalu titik kontrol sub-kuadratik dihitung dari rumus
  `ctrl = -0.5 * P_even_lo + 2.0 * P_onehalf - 0.5 * P_even_hi`
  (`src/path.rs:457-461`). Titik akhir kubik disalin ke `even_pts[n]`
  (`src/path.rs:447`).
- Layout buffer keluaran `[f32; 96]` (`src/path.rs:467-475`): `out[0..2]` =
  on-curve awal `P0`, lalu untuk setiap sub-kuadratik `k` dipakai 4 float
  berurutan `(ctrl_k.x, ctrl_k.y, endpoint_k.x, endpoint_k.y)`. Kapasitas
  `96 = 2 + 4 × 16` cukup untuk `MAX_QUADS = 16` sub-kuadratik tanpa alokasi
  heap.

### 2.3 Pemanggil

Dipanggil tepat satu kali, di `fill_impl` cabang `PathEvent::Cubic`
(`src/path.rs:228-229`):

```rust
let n = estimate_number_of_quadratic_curves(&lp, &c1, &c2, &tp, TOL);
let q = convert_cubics_to_quadratic_curves(simd, &lp, &c1, &c2, &tp, n);
```

Hasil `q` lalu di-iterasi `n` kali; setiap sub-kuadratik diteruskan ke
`emit_quadratic_and_flatten` (`src/path.rs:291`) yang memanggil
`flatten_quadratic` dari `src/flatten.rs` (lihat §4).

## 3. `estimate_number_of_quadratic_curves` (`src/path.rs:352-375`)

### 3.1 Signature

```rust
#[inline(always)]
fn estimate_number_of_quadratic_curves(
    p0: &Point<f32>,
    p1: &Point<f32>,
    p2: &Point<f32>,
    p3: &Point<f32>,
    accuracy: f32,
) -> usize
```

(`src/path.rs:351-358`).

### 3.2 Peran dan dokumentasi singkat

Tidak ada doc-comment eksplisit; ringkasan berdasarkan kode:

- Memperkirakan jumlah sub-kurva kuadratik `n` yang dibutuhkan untuk
  mengaproksimasi kubik `p0..p3` dalam toleransi `accuracy` (untuk
  pemanggilan dari `fill_impl`, `accuracy = TOL = 0.25`).
- Menghitung beda titik kontrol "diperluas" pada masing-masing ujung:
  `p1x2 = 3·p1 - p0` dan `p2x2 = 3·p2 - p3`, lalu
  `err = |p2x2 - p1x2|²` (kuadrat jarak Euklid).
- Membandingkan `err / max_hypot2` (di mana
  `max_hypot2 = 432 · (accuracy · TO_QUAD_TOL)²`) terhadap LUT 16 entri di
  `estimate` (`src/path.rs:377-390`):

```rust
const LUT: [f64; MAX_QUADS] = [
    1.0, 64.0, 729.0, 4096.0, 15625.0, 46656.0, 117649.0, 262144.0,
    531441.0, 1000000.0, 1771561.0, 2985984.0, 4826809.0, 7529536.0,
    11390625.0, 16777216.0,
];
```

- Mengembalikan indeks pertama `i + 1` dengan `err_div ≤ LUT[i]`; jika seluruh
  entri terlewati, jatuh ke pagar atas `MAX_QUADS = 16` (`src/path.rs:388-389`).
- Properti: nilai LUT setara dengan `(i+1)^6`, konsisten dengan analisis
  galat linearisasi kubik→kuadratik gaya Vello/Raph Levien (semakin lurus
  beda titik kontrol, semakin sedikit sub-kuadratik diperlukan; `n = 1`
  ketika `err_div ≤ 1`).

## 4. Alur De Casteljau midpoint subdivision di `src/flatten.rs`

### 4.1 Konstanta

```rust
const FLATNESS_THRESHOLD: i32 = 32;
```

(`src/flatten.rs:18`).

Doc-comment di atas konstanta menjelaskan satuan: nilai dalam 24.8 fixed-point,
sehingga `256 = 1.0 piksel` deviasi L1 (komentar memberi contoh `256` untuk
1.0 px; nilai aktif `32` ≈ 0.125 px deviasi L1, lebih halus). Komentar
(`src/flatten.rs:14-18`):

```text
/// Flatness tolerance
/// Uses L1 distance from chord midpoint to control point.
/// Threshold of 256 = 1.0 pixel L1 deviation (~0.5 px max curve deviation).
/// For coarser binning, increase to 512 or 768.
```

### 4.2 `flatten_quadratic` — entry point publik

Signature (`src/flatten.rs:20-29`):

```rust
pub fn flatten_quadratic<F>(
    p0x: i32, p0y: i32,
    p1x: i32, p1y: i32,
    p2x: i32, p2y: i32,
    callback: &mut F,
) where
    F: FnMut(i32, i32, i32, i32),
```

Doc-comment (`src/flatten.rs:1-12`) menyatakan:

- Fungsi melinearkan kurva Bézier kuadratik menjadi segmen garis lurus
  menggunakan metode "Blaze's recursive midpoint subdivision".
- Seluruh koordinat berada pada format **24.8 fixed point** (`i32` dengan
  konvensi `256 = 1 piksel`), yaitu format `F24Dot8` yang sama dengan output
  `f32_to_f24dot8` di `src/path.rs:333`.
- `callback` dipanggil sekali per segmen garis keluaran dengan tuple
  `(x0, y0, x1, y1)` dalam 24.8 fixed-point.

Implementasi: meneruskan langsung ke helper rekursif `flatten_recursive`
(`src/flatten.rs:30`).

### 4.3 `flatten_recursive` — pohon subdivisi

Signature (`src/flatten.rs:31-37`):

```rust
fn flatten_recursive<F>(
    p0x: i32, p0y: i32,
    p1x: i32, p1y: i32,
    p2x: i32, p2y: i32,
    callback: &mut F,
) where
    F: FnMut(i32, i32, i32, i32),
```

Alur (verbatim dari `src/flatten.rs:31-58`):

1. Cek terminasi via `is_flat_enough(p0, p1, p2)`.
2. **Kasus basis (flat):** emit satu segmen garis lurus dari `p0` ke `p2`
   dengan memanggil `callback(p0x, p0y, p2x, p2y)` — tepat empat `i32`
   F24Dot8 per pemanggilan (sesuai layout buffer di `src/path.rs:301-303`,
   `[p0x, p0y, p1x, p1y]`).
3. **Kasus rekursif (belum flat):** subdivisi De Casteljau di `t = 0.5`
   menggunakan pembagian bilangan bulat (truncating division) — komentar
   eksplisit menyebut bahwa shift aritmetika bertanda dihindari untuk
   mencegah drift 1-bit pada viewport bertanda:

   ```rust
   let m01x = (p0x + p1x) / 2;
   let m01y = (p0y + p1y) / 2;
   let m12x = (p1x + p2x) / 2;
   let m12y = (p1y + p2y) / 2;
   let midx = (m01x + m12x) / 2;
   let midy = (m01y + m12y) / 2;
   ```

   Lalu rekursi pada dua sub-kurva:
   - kiri: `(p0, m01, mid)`
   - kanan: `(mid, m12, p2)`

   (`src/flatten.rs:56-57`).

Karena `m01`, `m12`, dan `mid` sendiri adalah hasil pembagian bilangan bulat
F24Dot8, seluruh aritmetika sub-pohon tetap berada pada domain F24Dot8 tanpa
melalui floating-point. Rekursi berhenti ketika setiap daun lulus
`is_flat_enough`.

### 4.4 `is_flat_enough` — kriteria terminasi (`src/flatten.rs:62-87`)

Signature:

```rust
#[inline(always)]
fn is_flat_enough(
    p0x: i32, p0y: i32,
    p1x: i32, p1y: i32,
    p2x: i32, p2y: i32,
) -> bool
```

Doc-comment menjelaskan bahwa fungsi mengukur jarak L1 dari midpoint chord
`p0→p2` ke titik kontrol `p1`. Implementasi (`src/flatten.rs:71-86`):

- Degenerate guard: `p0 == p2` mengembalikan `true` (kurva titik tunggal).
- Hitung midpoint chord `m = ((p0x+p2x)/2, (p0y+p2y)/2)` dengan pembagian
  bulat F24Dot8.
- Hitung deviasi L1 `dc = |mx - p1x| + |my - p1y|`.
- Lulus jika `dc ≤ FLATNESS_THRESHOLD` (= 32 dalam F24Dot8 ≈ 0.125 piksel).

## 5. Jembatan f32 → F24Dot8 dan integrasi dengan `fill_impl`

`emit_quadratic_and_flatten` (`src/path.rs:289-308`) adalah satu-satunya
pemanggil `flatten_quadratic` di basis kode. Fungsi ini:

- Menerima titik `p0, p1, p2 : Point<f32>` dalam koordinat ruang piksel
  setelah transform affine.
- Mengonversi setiap koordinat ke F24Dot8 melalui `f32_to_f24dot8`
  (`src/path.rs:333-345`), yaitu pembulatan simetris dengan skala `× 256.0`.
- Memberikan callback yang menulis empat `i32` per segmen ke `line_buf`
  via `line_buf.extend_from_slice(&[x0, y0, x1, y1])`
  (`src/path.rs:301-303`). Komentar di sekitarnya
  (`src/path.rs:289-290`) menyatakan eksplisit bahwa setiap rekord adalah
  `4 i32s (F24Dot8) = [p0x, p0y, p1x, p1y]`.

Jalur lengkap untuk `PathEvent::Cubic` (`src/path.rs:213-256`):

1. Transform affine kubik via `transform_quad` (jalur SIMD f32x8,
   `src/path.rs:62-94`).
2. `n = estimate_number_of_quadratic_curves(..., TOL)` — `TOL = 0.25`.
3. `q = convert_cubics_to_quadratic_curves(simd, ..., n)` — buffer `[f32; 96]`.
4. Loop `for i in 0..n` membaca pasangan `(ctrl, end)` per sub-kuadratik dan,
   jika ada ekstrem-y, melakukan satu split eksplisit di parameter `t` lewat
   `find_quadratic_extrema` + `lerp` (`src/path.rs:235-251`); selain itu
   memanggil `emit_quadratic_and_flatten` langsung.
5. `emit_quadratic_and_flatten` → `f32_to_f24dot8` (×6 koordinat) →
   `flatten_quadratic` → `flatten_recursive` → callback yang push 4 × i32 ke
   `line_buf`.

Untuk `PathEvent::Quadratic` (`src/path.rs:188-201`) jalurnya sama tanpa
langkah konversi kubik→kuadratik.

## 6. Ringkasan klaim untuk Subbab 3.5

Klaim teknis yang dapat dirujuk dari Bab 3 berbasis fakta di atas:

- "Flattening kurva Arabella melakukan dua tahap di CPU: (i) konversi kubik ke
  rangkaian kuadratik via `convert_cubics_to_quadratic_curves`
  (`src/path.rs:391`) dengan jumlah sub-kuadratik ditaksir oleh
  `estimate_number_of_quadratic_curves` (`src/path.rs:352`); (ii) linearisasi
  kuadratik ke segmen garis dengan De Casteljau midpoint subdivision di
  `flatten_quadratic`/`flatten_recursive` (`src/flatten.rs:20`,
  `src/flatten.rs:31`)."
- "Output linearisasi adalah segmen garis pada format `F24Dot8` (24.8 fixed-
  point, `i32` dengan skala `256 = 1 piksel`); konversi `f32 → F24Dot8`
  dilakukan oleh `f32_to_f24dot8` (`src/path.rs:333-345`) dan setiap segmen
  disimpan sebagai empat `i32` `[p0x, p0y, p1x, p1y]`
  (`src/path.rs:289-308`)."
- "Kriteria terminasi subdivisi adalah jarak L1 antara midpoint chord dan
  titik kontrol kuadratik di bawah `FLATNESS_THRESHOLD = 32` dalam F24Dot8
  (`src/flatten.rs:18`, `src/flatten.rs:62-87`); aritmetika subdivisi
  memakai pembagian bilangan bulat untuk menghindari drift bit pada
  viewport bertanda (`src/flatten.rs:46-57`)."
- "Jumlah sub-kuadratik dibatasi `MAX_QUADS = 16` (`src/path.rs:7`),
  konsisten dengan kapasitas buffer keluaran `[f32; 96]` di
  `convert_cubics_to_quadratic_curves` (`src/path.rs:391-475`) dan look-up
  table 16 entri di `estimate` (`src/path.rs:377-390`)."
- "Toleransi konversi kubik→kuadratik yang dipakai pada hot path adalah
  `TOL = 0.25` (= `SQRT_TOL² = 0.5²`, `src/path.rs:10-11`), yang dipasangkan
  dengan `TO_QUAD_TOL = 0.5` (`src/path.rs:8`) untuk membentuk
  `max_hypot2 = 432 · (TOL · TO_QUAD_TOL)²` di
  `estimate_number_of_quadratic_curves` (`src/path.rs:352-375`)."
