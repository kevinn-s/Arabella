### 2.1 Struct dan signature `WebGlRenderer::new`

```rust
// src/render/webgl.rs:271-294
impl WebGlRenderer {
    pub fn new(canvas: &HtmlCanvasElement) -> Self {
        let context_options = js_sys::Object::new();
        js_sys::Reflect::set(&context_options, &"antialias".into(), &JsValue::FALSE).unwrap();
        js_sys::Reflect::set(&context_options, &"depth".into(), &JsValue::TRUE).unwrap();

        let gl = canvas
            .get_context_with_context_options("webgl2", &context_options)
            .expect("WebGL2 context to be available")
            .unwrap()
            .dyn_into::<WebGl2RenderingContext>()
            .expect("Context to be a WebGL2 context");

        assert!(
            gl.get_parameter(WebGl2RenderingContext::DEPTH_BITS)
                .unwrap()
                .as_f64()
                .unwrap() >= 24.0,
            "Depth buffer must be at least 24 bits"
        );

        let programs = WebGlPrograms::new(&gl);

        Self { programs, gl }
    }
```

Fakta penting:
- Konteks dibuat dengan `webgl2` (`get_context_with_context_options("webgl2", …)`).
- Opsi: `antialias = false`, `depth = true`.
- Asersi runtime: depth buffer minimal 24-bit.
- `WebGlPrograms::new(&gl)` (`src/render/webgl.rs:39-52`) memanggil
  `create_shader_program`, `get_tile_uniforms`, `create_webgl_resources`, dan
  `initialize_tile_vao(gl, &resources)` (`src/render/webgl.rs:47`).

### 2.2 Signature `WebGlRenderer::render`

```rust
// src/render/webgl.rs:296-311
pub fn render(&mut self, scene: &Scene, render_size: &RenderSize) {
    // Upload textures from scene
    self.programs.prepare(&self.gl, scene);

    // Clear
    self.gl.viewport(0, 0, render_size.width as i32, render_size.height as i32);
    self.gl.clear_color(1.0, 1.0, 1.0, 1.0);
    self.gl.clear_depth(1.0);
    self.gl.clear(
        WebGl2RenderingContext::COLOR_BUFFER_BIT | WebGl2RenderingContext::DEPTH_BUFFER_BIT,
    );

    // Draw
    self.gl.use_program(Some(&self.programs.tile_program));
    self.render_tiles(scene.tiles(), render_size);
}
```

Aliran `render`:
1. `self.programs.prepare(&self.gl, scene)` — upload tekstur segmen (TEXTURE0
   RGBA32F) dan tekstur segment list (TEXTURE1 R32UI) dari `Scene` (`src/render/webgl.rs:55-63`).
2. Set viewport sesuai `RenderSize`, clear color (1,1,1,1) + depth (1.0).
3. `use_program(tile_program)` lalu delegate ke `render_tiles(scene.tiles(), …)`.

`render_tiles` (private, `src/render/webgl.rs:313-403`) melakukan: upload UBO
`config`, bind 4 tekstur (segments / segment_list / encoded_paints / gradient),
upload `tiles` ke `tiles_buffer` sebagai `ARRAY_BUFFER`, bind `tile_vao`,
mengaktifkan `DEPTH_TEST` (`depth_mask(false)`) dan `BLEND`
(`SRC_ALPHA, ONE_MINUS_SRC_ALPHA`), lalu memanggil
`draw_arrays_instanced(TRIANGLE_STRIP, 0, 4, tiles.len() as i32)`
(`src/render/webgl.rs:393-398`) — satu instance per `Tile`.

### 2.3 Signature `initialize_tile_vao`

Fungsi modul-private (bukan method) yang mengonfigurasi VAO untuk instancing
dari buffer `Tile`. Deklarasi pada `src/render/webgl.rs:525`.

```rust
// src/render/webgl.rs:525-563
fn initialize_tile_vao(gl: &WebGl2RenderingContext, resources: &WebGlResources) {
    gl.bind_vertex_array(Some(&resources.tile_vao));
    gl.bind_buffer(WebGl2RenderingContext::ARRAY_BUFFER, Some(&resources.tiles_buffer));

    let stride = core::mem::size_of::<Tile>() as i32; // Automatically handles the size expansion

    // Attribute 0: x, y
    gl.enable_vertex_attrib_array(0);
    gl.vertex_attrib_i_pointer_with_i32(0, 1, WebGl2RenderingContext::UNSIGNED_INT, stride, 0);
    gl.vertex_attrib_divisor(0, 1);

    // Attribute 1: width, height
    gl.enable_vertex_attrib_array(1);
    gl.vertex_attrib_i_pointer_with_i32(1, 1, WebGl2RenderingContext::UNSIGNED_INT, stride, 4);
    gl.vertex_attrib_divisor(1, 1);

    // Attribute 2: backdrop [0..4] (First 4 elements of i16; 8)
    gl.enable_vertex_attrib_array(2);
    gl.vertex_attrib_i_pointer_with_i32(2, 4, WebGl2RenderingContext::SHORT, stride, 8);
    gl.vertex_attrib_divisor(2, 1);

    // Attribute 3: backdrop [4..8] (Last 4 elements of i16; 8)
    gl.enable_vertex_attrib_array(3);
    gl.vertex_attrib_i_pointer_with_i32(3, 4, WebGl2RenderingContext::SHORT, stride, 16); // Offset moves +8 bytes
    gl.vertex_attrib_divisor(3, 1);

    // Attribute 4: segments[2] (Pushed from location 3 to 4)
    gl.enable_vertex_attrib_array(4);
    gl.vertex_attrib_i_pointer_with_i32(4, 2, WebGl2RenderingContext::UNSIGNED_INT, stride, 24); // Offset moves to 24
    gl.vertex_attrib_divisor(4, 1);

    // Attribute 5: payload, paint_flag, depth_index (Pushed from location 4 to 5)
    gl.enable_vertex_attrib_array(5);
    gl.vertex_attrib_i_pointer_with_i32(5, 3, WebGl2RenderingContext::UNSIGNED_INT, stride, 32); // Offset moves to 32
    gl.vertex_attrib_divisor(5, 1);

    gl.bind_vertex_array(None);
}
```

### 2.4 Bukti stride 44 byte per-instance dan `vertexAttribDivisor`

Stride ditetapkan via `core::mem::size_of::<Tile>()` (`src/render/webgl.rs:529`).
Layout `Tile` (`#[repr(C)]`, `src/tile.rs:10-22`) menjumlahkan tepat 44 byte:

| Field                  | Tipe         | Ukuran | Offset kumulatif |
|------------------------|--------------|--------|-------------------|
| `x`                    | `u16`        | 2 B    | 0                 |
| `y`                    | `u16`        | 2 B    | 2                 |
| `width`                | `u8`         | 1 B    | 4                 |
| `height`               | `u8`         | 1 B    | 5                 |
| `_pad`                 | `[u8; 2]`    | 2 B    | 6                 |
| `backdrop`             | `[i16; 8]`   | 16 B   | 8                 |
| `segments`             | `[f32; 2]`   | 8 B    | 24                |
| `payload`              | `u32`        | 4 B    | 32                |
| `paint_and_rect_flag`  | `u32`        | 4 B    | 36                |
| `depth_index`          | `u32`        | 4 B    | 40                |
| **Total**              |              | **44 B** | **44**         |

Konsistensi stride dengan offset atribut di `initialize_tile_vao`:
- Attribute 0 — offset 0 (x+y dipack sebagai 1× `UNSIGNED_INT`, 4 B).
- Attribute 1 — offset 4 (width+height+`_pad` dipack sebagai 1× `UNSIGNED_INT`, 4 B).
- Attribute 2 — offset 8 (4× `SHORT` = `backdrop[0..4]`, 8 B).
- Attribute 3 — offset 16 (4× `SHORT` = `backdrop[4..8]`, 8 B).
- Attribute 4 — offset 24 (2× `UNSIGNED_INT` = bit-pattern `segments[0..2]`, 8 B).
- Attribute 5 — offset 32 (3× `UNSIGNED_INT` = `payload`, `paint_and_rect_flag`,
  `depth_index`, 12 B).

Offset terjauh (32) + lebar atribut (12) = 44, persis sama dengan
`size_of::<Tile>()`.

`vertexAttribDivisor` dipanggil dengan divisor `1` untuk setiap atribut 0–5
(`src/render/webgl.rs:534, 539, 544, 549, 554, 559`). Artinya seluruh 44 byte
dari satu `Tile` dianggap sebagai data per-instance, sehingga
`drawArraysInstanced(TRIANGLE_STRIP, 0, 4, tiles.len())` di
`src/render/webgl.rs:393-398` mengeluarkan satu quad (4 vertex via
`TRIANGLE_STRIP`) per ubin nontrivial.

## 3. Ringkasan untuk Subbab 3.4.3 (Sequence Diagram) dan 3.4.4 (Class Diagram)

Lima pesan kanonik (siap dipakai pada Task 2.6):

1. Aplikasi → `Scene`: `Scene::fill` / `Scene::stroke`
   (`src/scene.rs:70`, `src/scene.rs:117`).
2. `Scene` → `Builder`: `Builder::build_path(path, fill_rule, transform)`
   — flattening + binning DDA (`src/scene.rs:85`).
3. `Scene` → `Builder`: `Builder::generate_tiles(paint_index, Fill::NonZero,
   payload, paint_flag)` — propagasi backdrop kiri-ke-kanan + emisi semua ubin
   nontrivial (`src/scene.rs:88-89`).
4. Aplikasi → `WebGlRenderer`: `WebGlRenderer::render(&scene, &render_size)`
   yang menyerahkan vertex buffer (`scene.tiles()`) dan tekstur segmen
   (`scene.segments()`) ke GPU (`src/render/webgl.rs:296`,
   `src/render/webgl.rs:381-388`).
5. `WebGlRenderer` → GPU: vertex shader instanced quad
   (`draw_arrays_instanced(TRIANGLE_STRIP, 0, 4, tiles.len())`,
   `src/render/webgl.rs:393-398`) lalu fragment shader analitik tunggal pada
   `render_tile.frag`.

Class-diagram yang relevan untuk Task 2.7:
- `Scene` (`src/scene.rs:35-41`) memiliki field `builder: Builder` yang
  meng-encapsulate seluruh pipeline CPU.
- `WebGlRenderer` (`src/render/webgl.rs:265-269`) memiliki dua field privat
  `programs: WebGlPrograms` dan `gl: WebGl2RenderingContext`; method publik
  `new(&HtmlCanvasElement) -> Self` dan `render(&mut self, &Scene,
