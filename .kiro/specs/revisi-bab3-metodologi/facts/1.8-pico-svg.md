## Sintaks `transform` yang didukung

`fn parse_transform` (`src/pico_svg.rs:235–298`) memecah string transform pada `')'` lalu mencocokkan prefix berikut:

- `matrix(` — `src/pico_svg.rs:238`, enam float comma/space-separated, dipetakan ke `Affine::new([…])`.
- `translate(` — `src/pico_svg.rs:248`, dua float; selain itu jatuh ke `Affine::IDENTITY` (tidak ada cabang `translate(x)` satu argumen).
- `scale(` — `src/pico_svg.rs:262`, satu (`Affine::scale(x)`) atau dua argumen (`scale_non_uniform(x, y)`).
- `scaleX(` — `src/pico_svg.rs:277`, satu float.
- `scaleY(` — `src/pico_svg.rs:283`, satu float.

Token transform lain (mis. `rotate(`, `skewX(`, `skewY(`) jatuh ke arm fallback (`src/pico_svg.rs:289–292`) yang mencetak peringatan `Did not understand transform attribute …` dan mengembalikan `Affine::IDENTITY`. Artinya rotasi dan skewing dalam atribut `transform` tidak disokong.

## Konfirmasi: bukan SVG 1.1 Core penuh

`pico_svg.rs` adalah parser minimal demo, bukan implementasi SVG 1.1 Core. Dispatch tag-name di baris 191 hanya mencakup `"g"` dan `"path"`; arm fallback di baris 228 (`other => eprintln!("Unhandled node type {other}")`) menjadi bukti eksplisit bahwa elemen apa pun selain itu dilewati tanpa pemrosesan.

Konfirmasi via grep absence pada file `src/pico_svg.rs` (semua case-insensitive kecuali ditandai):

- `text|tspan|textPath` — tidak ditemukan kecocokan. Elemen teks (`<text>`, `<tspan>`, `<textPath>`) tidak ditangani.
- `defs` — tidak ditemukan kecocokan. Blok definisi terbagi (`<defs>`) tidak diparse.
- `gradient|linearGradient|radialGradient` — tidak ditemukan kecocokan. Gradien linear maupun radial tidak diproses; `parse_color` (`src/pico_svg.rs:299`) hanya menangani warna solid via `peniko::color::parse_color`.
- `pattern` — tidak ditemukan kecocokan. Pattern fill/stroke tidak disokong.
- `filter` — tidak ditemukan kecocokan. Tidak ada penanganan `<filter>` atau primitif `feGaussianBlur`/`feColorMatrix`/dst.
- `clipPath|mask` — tidak ditemukan kecocokan. Clipping path dan masking tidak diparse.
- `rect|circle|ellipse|polyline|polygon` — tidak ditemukan kecocokan. Bentuk dasar non-`path` tidak ditangani; pemakai harus mengirim setiap geometri sebagai `<path d="…">`.
- `image|symbol|use` — tidak ditemukan kecocokan. Penyisipan raster (`<image>`) maupun reuse simbol (`<symbol>` + `<use>`) tidak disokong.

Selain itu, atribut presentation lanjutan yang lazim pada SVG 1.1 Core juga absen: tidak ada pembacaan `style` (CSS inline), `class`, `font-*`, `text-anchor`, `stop-color`, `stop-opacity`, `clip-path`, `mask`, `filter`, `marker-*`, `paint-order`, `vector-effect`, atau `xml:space`. Pewarisan properti yang dilakukan terbatas pada `fill`/opacity (lihat `RecursiveProperties`, `src/pico_svg.rs:161–164`), dan komentar `// TODO: Handle recursive opacity properly` (baris 186, 223) menegaskan pewarisan opacity bahkan belum lengkap.

## Ringkasan untuk Bab 3

- Cakupan parser: subset minimal SVG—hanya `<g>` dan `<path>` dengan atribut presentation `fill`, `stroke`, `stroke-width` dan—pada `<g>`—`transform` (matriks/translasi/skala uniform/skala sumbu).
- Atribut tambahan yang juga dibaca: `fill-opacity`, `stroke-opacity`, `opacity` (per elemen, belum diwariskan); `width`, `height`, `viewBox` (pada elemen root `<svg>`); `d` (wajib pada `<path>`).
- Bukan SVG 1.1 Core lengkap: tidak menangani `text`, `defs`, gradient (linear/radial), pattern, filter, clipPath/mask, bentuk dasar `rect`/`circle`/`ellipse`/`polyline`/`polygon`, maupun `image`/`symbol`/`use`. Konfirmasi negatif diperoleh melalui grep absence terhadap `src/pico_svg.rs`.
- Konsumen utama: contoh demo di `examples/native_webgl/` dan suite tes di `tests/test.rs` yang memuat `assets/*.svg` (mis. `bismillah.svg`, `el_gato.svg`, `Ghostscript_Tiger.svg`, `paris-30k.svg`, `SVG_Logo.svg`).
