## Ringkasan

Seluruh enam belas heading wajib (`# BAB 3 METODE PENELITIAN` + 15 anggota Subbab_Wajib) hadir tepat satu kali pada level Markdown yang ditentukan, dengan teks case-sensitive persis sama. Nomor heading level 2 menaik monotonik dari 3.1 sampai 3.7 tanpa lompatan, pengulangan, atau pembalikan, dan setiap subheading `### 3.X.Y` muncul setelah induknya `## 3.X` dengan nomor `Y` menaik mulai dari 1. Tidak ditemukan heading H1/H2/H3 tambahan di luar daftar wajib.

## Metodologi Verifikasi

1. Pencocokan baris-penuh case-sensitive (`line == needle`) untuk seluruh 16 heading wajib pada berkas target, dengan menghitung jumlah kemunculannya.
2. Pemeriksaan baris pertama berkas (`lines[0] == "# BAB 3 METODE PENELITIAN"`).
3. Enumerasi seluruh baris yang diawali `#`, `##`, `###`, atau `####` untuk mendeteksi heading liar (stray headings) yang tidak terdaftar pada Subbab_Wajib.
4. Pemeriksaan ordering nomor baris pada urutan kanonik (H1 → 3.1 → 3.2 → 3.2.1 → 3.2.2 → 3.2.3 → 3.3 → 3.3.1 → 3.4 → 3.4.1 → 3.4.2 → 3.4.3 → 3.4.4 → 3.5 → 3.6 → 3.7) untuk memastikan strictly increasing.
5. Ekstraksi sub-sekuens H2 untuk membuktikan urutan nomor `3.1, 3.2, 3.3, 3.4, 3.5, 3.6, 3.7` tanpa lompatan/pengulangan/pembalikan.
6. Pengelompokan setiap H3 di bawah induk H2 berdasarkan rentang baris parent → next-parent, lalu memverifikasi bahwa nilai `Y` mulai dari 1 dan menaik berurutan tanpa celah.

Skrip implementasi: `validation/_verify_4_3.py` (dijalankan dengan Python 3, output tercantum di `OVERALL_PASS=True`).
