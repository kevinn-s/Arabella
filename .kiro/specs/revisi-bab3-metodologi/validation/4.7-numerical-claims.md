**Forbidden value scan — ukuran selain 44:** Pencarian `\b(40|42|46|48|52|56|64) byte\b` mengembalikan `0` kemunculan. Pencarian `\d+ byte` hanya mengembalikan kemunculan komponen field individual yang bersesuaian (1, 2, 4, 8, 16) atau angka 44 itu sendiri; tidak ada angka lain yang muncul sebagai klaim ukuran total `Tile`. Catatan: angka `40` dan `36` muncul pada kolom **Offset (byte)** Tabel 3.1 (baris 376–377) sebagai *offset* lapangan `paint_and_rect_flag` dan `depth_index`, bukan sebagai klaim total ukuran rekord; hal ini konsisten dengan total 44 byte (`offset 40 + width 4 = 44`). ✅

## Pemeriksaan Konsistensi Aritmetik Lintas Klaim

| Hubungan | Verifikasi |
|---|---|
| `TILE_W_F24DOT8 = 4096` ?= `TILE_W × 256` | $16 \times 256 = 4096$ ✅ |
| `TILE_H_F24DOT8 = 2048` ?= `TILE_H × 256` | $8 \times 256 = 2048$ ✅ |
| `WINDING_UNIT = 256.0` ?= $2^8$ (8.8 fixed-point) | $2^8 = 256$ ✅ |
| Penjumlahan field `Tile` ?= 44 byte | $2+2+1+1+2+16+8+4+4+4 = 44$ ✅ |
| `backdrop: [i16; 8]` lebar byte ?= 16 byte | $8 \times 2 = 16$ ✅ |
| `segments: [f32; 2]` lebar byte ?= 8 byte | $2 \times 4 = 8$ ✅ |
| Jumlah scanline backdrop ?= `TILE_H` | $8 = 8$ ✅ |
| Rentang `[0, 16]` × `[0, 8]` koordinat ubin lokal ?= dimensi ubin | sesuai $16 \times 8$ piksel ✅ |
| Offset terakhir pada Tabel 3.1 = 40, lebar = 4 ?= total 44 | $40 + 4 = 44$ ✅ |

## Verdict Akhir

**PASS.** Property 7 (Konsistensi Klaim Numerik) terpenuhi sepenuhnya:

1. Setiap parameter numerik kanonik (dimensi ubin 16×8, ukuran `Tile` 44 byte, kanvas tes 1080×520, format tekstur RGBA32F, fixed-point segmen F24Dot8, fixed-point akumulator 8.8) dilaporkan dengan **nilai yang sama** di seluruh `Skripsi/bab3_metodologi.md`.

Satu kemunculan literal `1920 \times 1080` hanya berfungsi sebagai disclaimer eksplisit yang menolak klaim tersebut, dan secara semantik tidak menyatakannya sebagai resolusi yang dipakai.
3. **Hubungan aritmetik silang antar konstanta** (`TILE_W_F24DOT8 = TILE_W × 256`, `TILE_H_F24DOT8 = TILE_H × 256`, `WINDING_UNIT = 2^8`, penjumlahan field `Tile` = 44 byte) konsisten satu sama lain dan dengan source code Arabella di `src/blocks.rs`, `src/builder.rs`, `src/tile.rs`, dan `src/render/shaders/render_tile.frag`.
