# Validasi Property 8 — Single-File Output Identity (Tugas 4.8)

- **Property:** 8 — Single-File Output Identity
- **Validates:** Requirements 1.1, 1.2, 1.3, 1.5
- **Target file kanonik:** `Skripsi/bab3_metodologi.md`
- **Tanggal validasi:** 2025 (waktu eksekusi tugas 4.8)
- **Tools yang dipakai:** Kiro `file_search`, `grep_search`, PowerShell `Get-ChildItem -Recurse -Force`, parser CommonMark Python (`commonmark` 0.9.x via `python -m pip install commonmark`).
- **Cakupan pemindaian:** seluruh akar repositori `e:\Users\Documents\A - TUGAS BINUS\Thesis\Code\` kecuali subpohon `.git\` (riwayat Git internal, bukan berkas kerja).

## 1. Pernyataan Property

> *For all* jalur berkas di repositori yang nama berkasnya mengandung substring `bab3`, `bab_3`, atau `bab-3` (pencocokan case-insensitive), satu-satunya berkas yang baris pertamanya adalah literal `# BAB 3 METODE PENELITIAN` adalah `Skripsi/bab3_metodologi.md`; dan tidak ada salinan utuh, salinan parsial, cadangan, atau draf alternatif Bab 3 di lokasi lain manapun pada repositori.

## 2. Hasil Pemindaian Nama Berkas

Perintah pemindaian (PowerShell, regex case-insensitive `(?i)bab[-_ ]?3` mencakup `bab3`, `bab_3`, `bab-3`):

```powershell
Get-ChildItem -Path "<repo>" -Recurse -File -Force `
  | Where-Object { $_.FullName -notmatch '\\\.git\\' } `
  | Where-Object { $_.Name -match '(?i)bab[-_ ]?3' } `
  | Select-Object -ExpandProperty FullName
```

Hasil (semua berkas yang nama berkasnya cocok pola, di luar `.git\`):

| # | Jalur | Klasifikasi |
|---|-------|-------------|
| 1 | `Skripsi\bab3_metodologi.md` | **Kanonik** — output Bab 3 pasca-revisi |

Perluasan ke seluruh entri (file + folder) untuk transparansi:

| # | Jalur | Tipe | Klasifikasi |
|---|-------|------|-------------|
| 1 | `Skripsi\bab3_metodologi.md` | file | Kanonik |
| 2 | `.kiro\specs\revisi-bab3-metodologi\` | folder spec | Metadata spec (nama folder cocok pola karena nama spec `revisi-bab3-metodologi`; bukan berkas, dan tidak ada berkas Bab 3 di dalamnya) |

Berkas-berkas di dalam folder `.kiro\specs\revisi-bab3-metodologi\` (`.config.kiro`, `requirements.md`, `design.md`, `tasks.md`, `facts/*.md`, `validation/*`) memiliki nama berkas yang **tidak** mengandung substring `bab3`, `bab_3`, atau `bab-3`, sehingga tidak masuk hitungan property. Berkas-berkas tersebut adalah artefak metadata spec, bukan salinan/draf konten Bab 3.

Hasil silang `file_search` Kiro untuk masing-masing pola substring (di luar `.git\`):

- `bab3` → 1 hit: `Skripsi\bab3_metodologi.md`
- `bab_3` → 0 hit
- `bab-3` → 0 hit

Pemindaian tambahan untuk menangkap kemungkinan cadangan/draf alternatif berdasarkan pola nama umum (`metodologi`, `metode penelitian`) dan ekstensi cadangan (`.bak`, `.old`, `.orig`, `.tmp`, `.swp`):

```powershell
Get-ChildItem ... | Where-Object {
    $_.Name -match '(?i)(bab.*3|metodologi|metode.penelitian)' `
    -or $_.Extension -in @('.bak','.old','.orig','.tmp','.swp')
}
```

Hasil: 1 berkas — `Skripsi\bab3_metodologi.md` (60 981 byte). Tidak ada cadangan, swap, draf, atau salinan dengan nama lain.

## 3. Hasil Pemindaian Konten (Heading Bab 3)

Perintah `grep_search` untuk regex `^# BAB 3 METODE PENELITIAN$` di seluruh `**/*.md`:

| # | Jalur | Baris pertama-cocok |
|---|-------|---------------------|
| 1 | `Skripsi\bab3_metodologi.md` | baris 1: `# BAB 3 METODE PENELITIAN` |

Pencocokan substring longgar `BAB 3 METODE PENELITIAN` (tanpa anchor `^...$`) menghasilkan kemunculan tambahan hanya di:

- `.kiro\specs\revisi-bab3-metodologi\design.md` — sebagai contoh literal di dalam blok pseudo-AST (diskusi spec, bukan konten Bab 3).
- `.kiro\specs\revisi-bab3-metodologi\tasks.md` — sebagai instruksi tugas validasi yang mengutip frasa heading.
- `.kiro\specs\revisi-bab3-metodologi\requirements.md` — sebagai kutipan literal di Acceptance Criteria 1.3 dan 1.4.
- `.kiro\specs\revisi-bab3-metodologi\validation\4.1-forbidden-terms.md` — laporan validasi yang mengutip frasa.

Tak satupun dari berkas tersebut menempatkan `# BAB 3 METODE PENELITIAN` sebagai **baris pertama** berkas, dan tak satupun adalah salinan/draf konten Bab 3 — semua adalah metadata spec yang mengutip frasa secara literal di dalam paragraf naratif. Klasifikasi: **spec metadata**, bukan alternatif draf.

## 5. Verifikasi Tidak Ada Salinan/Draf Alternatif

Pengecekan eksplisit:

- **Salinan utuh.** Tidak ditemukan berkas lain (`*.md`, `*.bak`, `*.old`, `*.orig`, `*.tmp`, `*.swp`) yang baris pertamanya `# BAB 3 METODE PENELITIAN`. → Tidak ada.
- **Salinan parsial.** Tidak ada berkas Markdown lain yang nama berkasnya mengandung `bab3`/`bab_3`/`bab-3`. Frasa `BAB 3 METODE PENELITIAN` hanya muncul sebagai kutipan literal di dalam dokumen spec (`requirements.md`, `design.md`, `tasks.md`, `validation/4.1-forbidden-terms.md`) yang bukan konten Bab 3 dan bukan berkas dengan baris pertama heading tersebut. → Tidak ada.
- **Cadangan.** Tidak ditemukan berkas dengan ekstensi cadangan (`.bak`, `.old`, `.orig`, `.tmp`, `.swp`) di seluruh repositori. → Tidak ada.
- **Draf alternatif.** Tidak ada berkas tambahan dengan nama seperti `bab3_metodologi_v2.md`, `bab3_draft.md`, `metodologi_old.md`, `bab3_metodologi_revisi.md`, dll. Pencarian berbasis substring nama-umum ("metodologi", "metode penelitian") hanya mengembalikan satu hit yaitu berkas kanonik. → Tidak ada.

Catatan: subpohon `.git\` mengandung satu objek dengan nama `d3\b8bab35628dfb3dd6b87d53aa0266c4cae40fa` yang secara substring mengandung huruf "bab3" sebagai bagian dari hash objek SHA-1 (`b8bab35...`). Ini adalah objek internal Git, bukan berkas kerja, dan tidak relevan terhadap property; secara eksplisit dikecualikan dari pemindaian.
