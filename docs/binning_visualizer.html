Binning phase — interactive walkthrough

Drag the line endpoints. Step through the algorithm or play it. The grid is the tile grid (default 16×16). The view box is the dashed rectangle; segments outside it are clipped. This mirrors process_line_segment from Pathfinder-style tile binning.
What is this algorithm doing?
The function takes one line segment of a path and figures out which tiles it crosses. For each tile it touches, it emits an add_fill with the clipped sub-segment. It walks tiles using the Amanatides–Woo DDA: t_max tracks the parametric distance to the next vertical/horizontal grid line, and t_delta is how much t_max advances per tile in each axis. Two extra bookkeeping rules: (1) when the segment crosses a top tile boundary, an auxiliary segment is emitted to or from the tile's top-left corner so the winding integral stays consistent across tiles whose tops lie above the view box; (2) when the segment crosses a right tile boundary, the destination tile's backdrop is incremented by ±1, recording a winding contribution from the implicit horizontal ray to the right edge.
